# Répartition des rôles

| Rôle                         | Responsable       | Remarque                                                  |
| ---------------------------- | ----------------- | --------------------------------------------------------- |
| MOA / Client (expert métier) | (simulé)          | Tranche les questions, fixe les priorités de valeur       |
| AMOA / Testeur               | [Membre 1]        | Écrit et exécute les tests d'acceptation                  |
| MOE / Programmeur            | [Membres 1, 2, 3] | Chacun accepte et estime ses propres tâches               |
| MOE / Coach                  | [Membre 2]        | Veille aux bonnes pratiques XP, à PEP 8 et au refactoring |
| MOE / Tracker                | [Membre 3]        | Mesure la vélocité et alimente les indicateurs            |

Les rôles de MOE (programmeur, coach, tracker) et d'AMOA (testeur) sont tenus par l'équipe de 3. Le MOA est simulé car aucun membre du groupe ne joue le client.
