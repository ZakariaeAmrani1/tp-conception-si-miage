# Suivi des décisions et interactions avec le client

Le MOA joue le rôle du client. Chaque question vient de `01_exigences.md`.

Statuts : **Ouvert** (à trancher), **Validé** (proposition acceptée), **Modifié** (décision différente de la proposition).

## 1. Questions au client

| ID   | Date | Question                                                                                                                  | Proposition                                                                                                                                                              | Décision (MOA) | Statut | Impact                                 |
| ---- | ---- | ------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------- | ------ | -------------------------------------- |
| Q-01 |      | Aucune commande de suppression n'existe alors que le sujet demande de supprimer des UE. Faut-il ajouter une commande ?    | Ajouter `DELETE UE <name>` : supprime l'UE de l'année sélectionnée. Si elle est mutualisée, seul le lien avec cette année est supprimé.                                  |                | Ouvert | EX-08, nouvelle story (priorité basse) |
| Q-02 |      | Comment distinguer `ASSIGN UE <name> <diplome> <year>` de `ASSIGN <ue> <teacher> <hours>` ?                               | Si le 1er mot après `ASSIGN` est `UE`, c'est la mutualisation. `UE` est un mot-clé interdit comme nom, donc il n'y a pas d'ambiguïté.                                    |                | Ouvert | Parser, EX-09, EX-11                   |
| Q-03 |      | Les noms sont-ils uniques par catégorie ou globalement ?                                                                  | Globalement, car `GET HOURS <name>` accepte un enseignant, une UE ou un diplôme.                                                                                         |                | Ouvert | RG-05, EX-12                           |
| Q-04 |      | L'identifiant d'un enseignant est-il le nom seul ?                                                                        | Oui, le nom seul. Un 2e enseignant de même nom est refusé, même avec un autre prénom (p.15).                                                                             |                | Ouvert | EX-10, RG-05                           |
| Q-05 |      | Une UE mutualisée est-elle comptée une fois ou une fois par diplôme dans les totaux `ALL` ?                               | Une seule fois dans `ALL`. Dans un diplôme donné, elle est comptée normalement.                                                                                          |                | Ouvert | EX-12, EX-13, EX-14                    |
| Q-06 |      | Le contrôle des 60 ECTS est-il bloquant à chaque ajout d'UE ?                                                             | Non. Le contrôle ne bloque pas la création. Un avertissement s'affiche dans `DISPLAY GRAPH` si une année n'a pas 60 ECTS. Un dépassement de 60 est refusé à la création. |                | Ouvert | RG-01, EX-06, EX-15                    |
| Q-07 |      | Peut-on affecter plus d'heures à une UE que son total ? Peut-on affecter plusieurs fois le même enseignant à la même UE ? | Refuser tout dépassement du total de l'UE. Un nouvel `ASSIGN` du même enseignant sur la même UE s'ajoute aux heures existantes.                                          |                | Ouvert | EX-11, RG-04, RG-13                    |
| Q-08 |      | Les heures CM, TD et TP doivent-elles être des multiples de 2 (séances de 2h) ?                                           | Oui, refuser les valeurs impaires (tous les exemples du sujet sont pairs).                                                                                               |                | Ouvert | RG-10, EX-06, EX-07                    |
| Q-09 |      | Que fait `EDIT UE` sur une UE mutualisée ? Que devient une UE si on renomme un diplôme ?                                  | La modification s'applique partout où l'UE est utilisée (c'est le même objet). Renommer un diplôme ne casse aucun lien.                                                  |                | Ouvert | EX-07, EX-09                           |
| Q-10 |      | Quand l'état est-il sauvegardé et rechargé ? Le sujet ne définit aucune commande.                                         | Sauvegarde automatique après chaque commande qui modifie les données, dans `data/offre.json`. Chargement automatique au démarrage s'il existe.                           |                | Ouvert | EX-17                                  |
| Q-11 |      | `GET HOURS` / `GET COST` sur un enseignant : que renvoie-t-on ?                                                           | `GET HOURS <enseignant>` renvoie ses heures. `GET COST <enseignant>` est refusé avec un message (le coût ne concerne que UE, diplôme, ALL).                              |                | Ouvert | EX-12, EX-13                           |
